# 見出しと目次のルール（節のページ）

[← README に戻る](../README.md)

学習ページ（第1〜3章の各節）の見出し・目次の付け方と、守られているかを確かめるテストをまとめる。読むのは、試験の勉強をする人。「ここに何が書いてあるか」を、上から読み進めなくても分かり、あとで読み返すときに目当ての場所へ戻れることを基準にする。

## ページの見出しの構造

| 見出し | 出どころ | 役割 |
|---|---|---|
| h1 | パンくず（`src/components/Breadcrumbs.tsx`）の最後の項目 | ページの題名。例：「1節：消防法の法体系」。ページに1つ |
| h2 | 各ページの `page.tsx` | 節の中の大きな区切り。ページの中身の見取り図になる |
| h3・h4 | 各ページの `page.tsx` | h2 の中の囲み（「まずはここだけ押さえよう」「出る出るポイント！」など） |

## ルール

1. **h2 は、その節に何が書いてあるかが、見出しだけで分かる言葉にする。** 付ける前に、節の中身（表・図・クイズを含む）を読む。
2. **h2 を、h1 と同じ言葉にしない。** 題名がすぐ下にもう一度出て、同じ題名が2回並ぶ。（テストで確かめる）
3. **同じページの中で、同じ言葉の h2 を2回出さない。**（テストで確かめる）
4. **表の節の h2 には、何の表（何の例）かまで書く。** 表の列の見出しは、その列に入っているものをそのまま言う言葉にする。
5. **試験の用語は、本文と同じ表記にする。** 例：「法令」は消防法・政令・規則をまとめて指し、「法」「政令」「規則」はそれぞれの略。
6. **「クイズ」は、ページの最下部にあり、読んだ内容の確認だと分かるので、そのままにする。**
7. **ソース（JSX）の中で、日本語の文を途中で改行しない。** 改行が、表示では不要な空白になる（例：「添えて、 当該免状」）。

見出しを付けるときは、見出しの数に決まりはない。Google の公式の文書も、「見出しはユーザーが見やすいように付ける」「見出しの理想の数はない」と述べている（[SEO スターターガイド](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)）。

## 目次

- 節のページの先頭（h1 の直後）に、`SectionToc`（`src/components/SectionToc.tsx`）で「このページの内容」を置く。
- 目次は、ページの h2 を、すべて同じ順番・同じ文言で並べる。各 h2 に `id` を付け、目次のリンクは、その `id` を指す。
- 目次の題名（「このページの内容」）は、h2 にしない。見出しの一覧や、重複の検査に混ざるため。目次は `<nav aria-labelledby="toc-title">` で、題名が名前になる。
- 固定のヘッダーに隠れないよう、節の h2 には `scroll-margin-top` を付けてある（`src/app/basics/BasicsShared.module.css`）。ヘッダーの高さは、スマートフォンで56px、パソコンで99px。
- ページに目次を足すには、`page.tsx` に目次の定数（`TOC_ITEMS`）を書き、各 h2 に `id` を付けて、`<SectionToc items={TOC_ITEMS} />` を `site-main` の先頭に置く。h2 の文言を変えたときは、目次の文言も直す。

## 直した例（1節：消防法の法体系）

| 直す前の h2 | 直したあとの h2 | 理由 |
|---|---|---|
| 消防法の法体系 | 法律・政令・省令の3層構造 | h1 と同じ意味だった |
| 用語と仕組み | 法令・法・政令・規則の違いと読み替え | 何の用語か分からなかった |
| 法・政令・規則の例 | 法律・政令・規則の具体例：免状の交付 | 何の例か分からなかった |

表の列の見出しは、「種別」「条文」から、「法令・条」「規定の内容」に直した。1列目には法令の区分と条の番号・見出しが、2列目にはその条が定める内容が入っているため。

## テスト

`src/app/basics/sectionHeadings.test.tsx` が、節のページをすべて描画して、次を確かめる。

- どのページにも、h1 と h2 がある
- 同じページの中で、同じ言葉の h2 がない
- h1 と同じ言葉の h2 が残っているのは、「直していないページの一覧」（テストファイルの `NOT_FIXED_YET`）にあるページだけ
- 目次のあるページでは、目次が h2 をすべて、同じ順番・同じ文言で、h2 の `id` へのリンクとして並べている（見出しを直して、目次を直し忘れると失敗する）

新しいページが、h1 と同じ言葉の h2 を持つと、テストが失敗する。ページを直したら、そのページを一覧から外す。外し忘れても、テストが失敗する（直したのに一覧にあるページが、一致しなくなるため）。一覧がすべて空になったら、一覧そのものと、この節の説明を消す。

章トップ（第1〜3章）は、`src/app/basics/chapterHubHeadings.test.tsx` が別に確かめている。
